# Código Fuente


## Descripción
Esta carpeta contendrá todo el código fuente de *AdminEasy*.
El proyecto será organizado por módulos con el objetivo de mantener una arquitectura clara, modular y fácil de mantener.


## Organización
*Modelos*
Contendrá las clases que representan las entidades principales del sistema.


*Estructuras*
Contendrá las implementaciones de las estructuras de datos desarrolladas durante el curso.


*Servicios*
Contendrá la lógica de negocio de la aplicación.


*Controladores*
Gestionará la comunicación entre la interfaz de usuario y la lógica del sistema.


*Utilidades*
Contendrá funciones y clases auxiliares reutilizables.


## Objetivo
Mantener una estructura organizada del código fuente que facilite el desarrollo colaborativo y el mantenimiento del proyecto.
