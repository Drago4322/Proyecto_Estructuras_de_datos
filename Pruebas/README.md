# Pruebas


## Descripción
Esta carpeta contendrá las pruebas realizadas sobre los diferentes módulos de AdminEasy con el propósito de verificar su correcto funcionamiento y detectar posibles errores durante el desarrollo.
Las pruebas se incorporarán progresivamente conforme se implementen las funcionalidades del sistema.


## Contenido
Actualmente esta carpeta no contiene archivos de prueba, ya que estos serán desarrollados durante la implementación del proyecto.


## Objetivo
Garantizar el correcto funcionamiento de la aplicación mediante la validación de las funcionalidades implementadas durante el desarrollo del proyecto.
