# Datos

## Descripción
Esta carpeta almacenará toda la información utilizada por AdminEasy para la persistencia de los datos del sistema.
Dependiendo de la evolución del proyecto, aquí podrán ubicarse archivos de configuración, bases de datos locales o cualquier otro recurso destinado al almacenamiento de la información.

## Contenido
Actualmente esta carpeta no contiene archivos, ya que la estrategia de almacenamiento será definida durante el desarrollo del proyecto.

## Objetivo
Centralizar y organizar todos los archivos relacionados con la persistencia de la información utilizada por el sistema.
