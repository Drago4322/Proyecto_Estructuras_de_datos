# Documentación


## Descripción
Esta carpeta contiene toda la documentación técnica y funcional del proyecto *AdminEasy*.
Su propósito es documentar el análisis, diseño, desarrollo y funcionamiento del sistema durante todas las etapas del proyecto.


## Contenido
*Arquitectura.md*
Describe la organización general del sistema, los módulos que lo conforman y la responsabilidad de cada uno de ellos.


*ModeloDeDatos.md*
Contendrá las entidades principales del sistema, sus atributos y las relaciones existentes entre ellas.


*CasosDeUso.md*
Describirá las funcionalidades disponibles para los usuarios del sistema y el comportamiento esperado de cada una.


*EstructurasDeDatos.md*
Documentará las estructuras de datos implementadas dentro del proyecto, indicando su propósito y la justificación de su utilización.


## Objetivo
Mantener organizada toda la documentación del proyecto y servir como apoyo durante el desarrollo, mantenimiento y presentación del sistema.
