# Recursos


## Descripción
Esta carpeta almacenará todos los recursos complementarios utilizados por AdminEasy durante su desarrollo y funcionamiento.
Aquí podrán incorporarse imágenes, logotipos, iconos, diagramas, archivos multimedia y cualquier otro recurso necesario para el proyecto.


## Contenido
Actualmente esta carpeta no contiene recursos, los cuales serán incorporados conforme avance el desarrollo del proyecto.


## Objetivo
Mantener organizados todos los recursos utilizados por la aplicación y facilitar su administración durante el desarrollo del proyecto.
